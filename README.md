# Car_Price

🚗 Car Price Prediction (توقع أسعار السيارات)

نموذج تعلم آلة (Machine Learning) للتنبؤ بأسعار السيارات المستعملة بناءً على مواصفاتها المختلفة مثل سنة الصنع، المسافة المقطوعة، نوع الوقود، وسعة المحرك.

## 📋 نظرة عامة على المشروع (Overview)
يهدف هذا المشروع إلى مساعدة المشترين والبائعين في تقدير السعر العادل للسيارات في السوق. تم بناء النموذج وتدريبه باستخدام خوارزميات الانحدار (Regression) لتحقيق أعلى دقة ممكنة في التوقعات.

## ✨ المميزات (Features)
* **تحليل البيانات الاستكشافي (EDA):** دراسة العلاقات بين مواصفات السيارة وسعرها.
* **معالجة البيانات (Data Preprocessing):** تنظيف البيانات، التعامل مع القيم المفقودة، وتحويل البيانات النصية (Encoding).
* **مقارنة النماذج:** اختبار عدة خوارزميات (مثل Linear Regression, Random Forest, XGBoost) واختيار الأفضل.
* **واجهة مستخدم بسيطة:** [اذكر هنا إذا كنت قد استخدمت Streamlit أو Flask لعرض المشروع].

## 📊 البيانات المستخدمة (Dataset)
تم استخدام مجموعة بيانات تحتوي على [اكتب عدد الصفوف، مثلاً: 10,000] سجل للسيارات، وتشمل الأعمدة التالية:
* `Brand / Model`: الشركة المصنعة وموديل السيارة.
* `Year`: سنة الصنع.
* `Mileage`: المسافة المقطوعة (بالكيلومتر).
* `Fuel Type`: نوع الوقود (بنزين، ديزل، كهرباء، هايبرد).
* `Transmission`: ناقل الحركة (أوتوماتيك، يدوي).
* `Engine Size`: سعة المحرك.
* `Price`: السعر (المتغير المستهدف - Target).
